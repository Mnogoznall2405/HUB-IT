## Карта проверенных границ

- Web: React/Vite/MUI и lazy-маршруты с `ProtectedRoute`/`PermissionRoute` в [App.jsx](../WEB-itinvent/frontend/src/App.jsx). FastAPI включает доменные роутеры в [main.py](../WEB-itinvent/backend/main.py); [chat_main.py](../WEB-itinvent/backend/chat_main.py) может обслуживать chat отдельно. Клиентские `capabilities` не заменяют серверный контроль.
- PostgreSQL хранит app/chat и отдельные контуры scan/voice; фактический layout legacy chat проверять до выката. SQL Server — legacy ITINVENT/оборудование. Chat WS, outbox и фоновые workers имеют отдельные пути запуска; смотреть [реализацию WS](../WEB-itinvent/backend/api/v1/chat/ws.py), [outbox](../WEB-itinvent/backend/chat/event_outbox_service.py) и [конфиг PM2](../scripts/pm2/ecosystem.all.config.js).
- Корпоративный ИИ: [оркестратор](../WEB-itinvent/backend/ai_chat/service.py), tools, отдельный [sandbox worker](../WEB-itinvent/backend/ai_sandbox/worker.py) и общий [LLM gateway](../shared/llm/). Auth: [AUTH_SECURITY_STACK.md](../documentation/technical/AUTH_SECURITY_STACK.md); текущие клиентские сессии не сводятся к старой модели «один Bearer в localStorage».
- Desktop: [App.xaml.cs](../desktop/Hub.Desktop/App.xaml.cs) действительно позволяет нативное окно; [ADR-0010](../docs/adr/0010-desktop-native-screens.md) и WebView2 сосуществуют. Native chat не развиваем до явного решения. Мобильный клиент — [Expo Android](../mobile-hub/README.md). Inventory и Scan — разные рантаймы; обязательные зависимости не добавлялись.
- IIS раздаёт опубликованный каталог, [publish](../scripts/iis/publish_frontend_iis.ps1) копирует туда сборку из `dist`; build сам по себе не deploy. Пакет/manifest и rollout — [release runbook](../scripts/releases/README.md). Текущие состояния окружений из этих инструкций не следуют.
