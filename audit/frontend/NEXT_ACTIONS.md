## Незакрытые вопросы (требуют действий/решений)

1. **FE-0004 (Suspected): исходное наблюдение (экран входа на /shared-folders/:invalid)
   не воспроизводится в чистом профиле** — деплой в окне наблюдения исключён (IIS-файлы
   не менялись с 20.11 15:10). Осталось: повторить наблюдение в профиле владельца
   (где оно фиксировалось) и решить политику обновления SW (skipWaiting только по
   сообщению — устаревшие shell'ы после деплоев; возможно, подсказка «доступна новая версия»).
2. **FE-0056: причина 400 при удалении/перемещении черновика** — воспроизвести с захватом
   тела ответа (вероятно `Message not found` из `mail_message_actions.py:83–94`); заодно
   live-проверить видимость Alert ошибки в UI (путь существует: setError → Alert).
   Смежное: FE-0077 — медленные `/drafts/upsert-multipart` (7–26 с по логам backend).
3. **FE-0059 (High): решение владельца по grace-окну ротации** (15 с → 60–120 с для web
   или мягкое восстановление) + замер метрик `refresh_reuse_detected` /
   `refresh_expired_or_already_used`. FE-0015/0016 закрыты этим же решением.
4. **Инцидент с удалением файлов `audit/frontend/`** — закрыт (удаление выполнил владелец).
   Несанкционированная сборка Desktop 21:45–22:48 — источник не установлен (не владелец,
   не субагенты по их ответам); остаточные dotnet-узлы простаивали и завершатся сами.
