# Аудит web-фронтенда HUB-IT (WEB-itinvent/frontend)

Непрерывный глубокий аудит веб-версии. Цель — найти реальные, воспроизводимые
дефекты фронтенда и подтвердить их доказательствами. Исправление дефектов — отдельные
задачи с разрешения владельца; этот аудит код приложения не меняет.

## Объект аудита

- Код: `WEB-itinvent/frontend/src` (React 18, Vite 7, MUI 5, react-router-dom 7)
- Маршруты: `WEB-itinvent/frontend/src/App.jsx` (36 маршрутов)
- Production frontend: IIS (`C:\inetpub\wwwroot\itinvent`, https://hubit.zsgp.ru/)
- Живые проверки: read-only + мутационные сценарии на заведомо тестовых данных
  (согласованы владельцем 2026-11-22; все тестовые данные удалены после проверки).

## Правила

1. Один дефект — одна запись (ID `FE-NNNN`); повторное обнаружение дополняет карточку.
2. `Confirmed` — только с фактическими доказательствами; иначе `Suspected`.
3. Пути и номера строк — только реально проверенные.
4. Без секретов, токенов, персональных данных и конфиденциальных ответов API.
5. Production — read-only по умолчанию; мутации — только тестовые данные с явного
   согласия владельца и с полной зачисткой после проверки.
