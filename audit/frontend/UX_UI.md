# UX/UI находки и предложения (не дефекты)

Отдельно от ISSUES.md: наблюдения и рекомендации, не являющиеся подтверждёнными ошибками.
Дефекты доступности/визуала со статусом Confirmed живут в ISSUES.md (FE-0002, 0003, 0009,
0010, 0011, 0014, 0022, 0024–0028, 0034, 0035, 0044…).

## Поведение/UX-наблюдения

1. **Ошибка входа исчезает через 5.2 с** (Login.jsx:593–616, `showLoginNotice(..., 5200)`).
   Пользователь, отвлёкшийся на ввод, может не увидеть причину отказа. Рекомендация:
   для ошибок авторизации — постоянный баннер с кнопкой закрытия.
2. **Уведомление о «1С временно недоступна» показывает возраст снимка в сырых секундах**
   («169 979 сек», /construction). Нечитаемо; рекомендация — человеческий формат («2 дня»).
3. **PWA-баннер установки подавляется, свой не показывается** (console: «Banner not shown:
   beforeinstallpromptevent.preventDefault() called…»). Проверить, задумано ли; возможно,
   стоит показывать собственный ненавязчивый prompt.
4. **`/it/requests` без параметра молча открывает первую активную заявку** — URL меняется
   на `/it/requests/{ref}`. Удобно, но неожиданно; помогает навигации «назад».
5. **Два механизма «админского» доступа**: `/admin/*` пускает по правам
   (`canAccessAdminArea`), а `/dlp`, `/file-egress` — только при `role==='admin'`.
   Одна и та же учётка видит админку, но не DLP-разделы. Согласовать модель доступа
   (продуктовое решение; клиентские проверки прав — только UX, сервер должен проверять сам).
6. **Дубликаты в алерте «Новые изменения оборудования на ПК»** (`BELG-ENRGY-0001-D` дважды,
   /computers) — возможно, слияние списков из нескольких баз без дедупа (FE-0008).

## Дизайн-система (сводно; детали у агента A)

- **Двойная система стилей**: Tailwind (Login, чат) против MUI sx (остальное) + CSS-переменные
  `--chat-*`. Поддерживать согласованность сложнее; долгосрочно — выбрать одну.
- **Тема**: `theme/index.js:31` — только `mode:'light'`. AGENTS.md требует «keep … dark
  theme», dark-ветки в officeUiTokens/chatTelegramTheme не активируются — противоречие
  документации и кода (записано как FE-0039; требует решения владельца: либо убрать требование
  из правил, либо включить dark-режим).
- Положительное: единые MUI-токены на большинстве страниц, мобильные рядки таблиц с
  role/tabIndex (Warehouse1C mobile — образец), BrandedRouteLoader на route-fallback.

## Проверенные UX-паттерны, работающие хорошо

- Redirect-ы по правам: недоступный маршрут тихо ведёт на первый доступный (без ошибок).
- Публичные страницы файлов: понятная ошибка + кнопка «Повторить загрузку».
- Поиск адресной книги: корректный debounce.
- Колокольчик: фокус внутри, Esc, возврат фокуса на кнопку.
- Пустые состояния встречаются («Нет непрочитанных уведомлений», «Папка пуста»).
