# UX/UI находки и предложения (не дефекты)

Дефекты со статусом Confirmed — в ISSUES.md. Здесь — наблюдения и рекомендации.

## Поведение/UX

1. **Ошибка входа исчезает через 5.2 с** (`Login.jsx:593–616`) — легко пропустить.
   Рекомендация: постоянный баннер с кнопкой закрытия для ошибок авторизации.
2. **Возраст снимка 1С в сырых секундах** («169 979 сек», /construction) — нечитаемо;
   нужен человеческий формат («2 дня»).
3. **PWA-баннер установки подавлен, свой не показывается** (console: «Banner not shown:
   beforeinstallpromptevent.preventDefault() called…»). Проверить, задумано ли.
4. **`/it/requests` без параметра молча открывает первую активную заявку** — удобно,
   но неожиданно; помогло навигации «назад».
5. **Два механизма «админского» доступа**: `/admin` пускает по правам
   (`canAccessAdminArea`), `/dlp` и `/file-egress` — только при `role==='admin'`.
   Одна учётка видит админку, но не DLP-разделы. Согласовать модель (клиентские
   проверки — только UX; сервер обязан проверять сам).
6. **Дубль учётных записей одного сотрудника** в справочнике (две AD-записи,
   идентификаторы обезличены) — данные AD; не фронтенд.
7. **Композер письма: нет явной кнопки закрытия** — только Escape (диалог сохранения
   черновика при этом отличный).
8. **Подтверждения разнотипны**: удаление задачи — нативный `window.confirm`
   (FE-0058), папки/сообщения/черновики — MUI-диалоги.
9. **Несвежий список задач после создания** — задача появилась только после смены
   скоупа (возможно, назначение на дублирующую учётку; повтор нужен) — Suspected.

## Дизайн-система

- Двойная система стилей: Tailwind (Login, чат) против MUI sx (остальное) + `--chat-*`
  (FE-0038) — долгосрочно выбрать одну.
- Тема light-only при требовании AGENTS.md «keep dark theme» (FE-0039) — решить
  владельцу: либо убрать требование, либо включить dark-режим.
- Положительное: единые MUI-токены на большинстве страниц; мобильные рядки таблиц
  (Warehouse1C mobile — образец с role/tabIndex/Enter); BrandedRouteLoader; диалоги
  MyFiles/чата с корректными заголовками и aria-семантикой.

## Проверенные UX-паттерны, работающие хорошо

- Redirect-ы по правам: недоступный маршрут тихо ведёт на первый доступный.
- Публичные страницы файлов: понятная ошибка + «Повторить загрузку».
- Поиск адресной книги: корректный debounce.
- Колокольчик: фокус внутри, Esc, возврат фокуса.
- Пустые состояния («Нет непрочитанных уведомлений», «Папка пуста», «Вложений пока нет»).
- Каскадная валидация создания задачи с текстом причины у кнопки.
- Диалоги удаления папки/сообщения с понятными текстами и MUI-семантикой.
