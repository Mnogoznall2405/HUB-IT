# WPF_MAIL_UI_AUDIT.md — аудит и переработка UI/UX нативной почты

Живой журнал итераций `AUDIT → DESIGN → IMPLEMENT → BUILD → SCREENSHOT → TEST → REVIEW → REPEAT`
для страницы «Почта» нативного клиента (`desktop/Hub.Desktop/Native`).

Верификация: `dotnet test desktop/Hub.Desktop.sln -c Debug --filter "FullyQualifiedName~NativeMailViewModelTests|FullyQualifiedName~NativeScreenshots"`
(STA-харнесс `NativeScreenshots` рендерит реальное `HubWindow` в PNG `desktop/screenshots/`, 1280×800,
тёмная + светлая темы; пиксельные проверки — PowerShell-скриптом; WCAG-контраст считается по
формуле из палитр `HubColorsDark/Light.xaml`).

## Итерация 5 — «Восстановить» из «Удалённых» (undo-паттерн Gmail)

Веб-почта уже умеет restore (`POST /mail/messages/{id}/restore`), нативный клиент — нет.

- API: `RestoreMailMessageAsync` в `IHubApiClient`/`HubApiClient` (через общий
  `PostMailMessageActionAsync`, action `restore`, body `{mailbox_id}`); фейк для тестов с
  записью вызовов и инъекцией сбоя.
- VM: `RestoreItemCommand` — параметр строка списка **или** открытая деталь; после `ok`:
  строка уходит из выдачи (`RemoveListItem` пересчитывает бейдж непрочитанных и агрегат),
  открытая деталь этого письма закрывается, дерево папок обновляется, статус «Письмо
  восстановлено»; `!ok` и исключение — баннер, строка остаётся.
- UI: кнопка «Восстановить» в панели действий шапки (видна только в «Удалённых»,
  `IsTrashFolder`) + пункт в kebab-меню строки.

Проверки итерации 5: **84/84** тестов (+3: restore из строки, restore из открытой детали,
сбой → баннер); пиксельная проверка стабильна; **Release-превью пересобрано — 0 ошибок**
(параллельная сессия сама починила свой `VectorIcon.cs`):
`desktop\Hub.Desktop\bin\mail-preview\HUB.Desktop.exe --native` содержит все итерации 1–5.

## Итерация 6 — вложенность папок (дерево parent_id)

Выгрузка `/mail/folders/tree` отдаёт плоский список с `parent_id`/`child_folder_count`, но
`ApplyFolderTree` его сортировал плоско — вложенные папки рендерились верхним уровнем.

- VM: `MailFolderViewModel` получил `Depth`, `HasChildren`, `IsExpanded` (сессия, по умолчанию
  раскрыто — как TB/Outlook), `IsTreeVisible`, `IndentWidth` (+16/уровень), `ChevronText`
  (MDL2 E70D/E76C), ссылку `Parent` и `UpdateTreeVisibility()` по цепочке предков.
- `ApplyFolderTree` перестроен в **DFS**: корни по рангу+label, дети следуют за родителем,
  «осиротевшие» узлы (parent_id вне выдачи) показываются корнями.
- `ToggleFolderExpandedCommand`: chevron сворачивает/разворачивает ветку; свёрнутые узлы
  не занимают место (триггер `IsTreeVisible` в стиле строки).
- UI строки: колонки отступа (16px/уровень) и chevron (виден только у родителей);
  «Показать ещё»/меню «Переместить» автоматически наследуют DFS-порядок.
- Демо-данные харнесса: вложенная «Архитектура ПО» под «Проекты ИТ» — скриншот показывает
  chevron и отступ.

Проверки итерации 6: **86/86** тестов (+2: DFS-порядок/глубина/отступы; сворачивание скрывает
детей, разворачивание возвращает); пиксели: `NeutralBadge` 228 → **246** — бейдж вложенной
демо-папки реально отрисован, остальные маркеры стабильны; Release-превью пересобрано — 0 ошибок.

## Итерация 7 — infinite scroll (автодо-загрузка у конца списка)

  `ScrollViewer` (`ScrollToEnd`) и снимает `07c-mail-scrolled.png` в обеих темах.

### ЭТАП 1 — белый прямоугольник (первопричина найдена и устранена)

**Диагноз**: `WebView2.Height` был привязан к `ScrollViewer.ViewportHeight`, а сам
HWND (`HwndHost`) находился ВНУТРИ скроллируемого `StackPanel` внутри `ScrollViewer`.
WPF `ScrollViewer` не клипает дочерние HWND — WebView2 растягивался на всю высоту
вьюпорта (независимо от длины письма) и **вылезал за границы панели до нижней
границы окна**, перекрывая статус-бар. В тёмной теме белый `DefaultBackgroundColor`
превращал его в гигантский белый прямоугольник.

**Фикс (не закрашивание, а архитектура)**: чтение разделено на Grid-строки:
- Row 0 (`Auto`, MaxHeight=340): `DetailScrollViewer` — шапка (тема/от/действия/
  вложения/заголовки/AI), собственный скроллер;
- Row 1 (`*`): фиксированная область тела — `TextBlock` fallback + `MailBodyHost`
  (WebView2 лениво). HWND получает **точные границы строки Grid** — не может
  вылезти. Высота больше не привязана к вьюпорту; размер задаёт Grid.
- Прокрутка: шапка скроллится своим скроллером; длинный HTML — внутри браузера.
