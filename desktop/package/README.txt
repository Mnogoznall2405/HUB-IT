HUB Desktop — сборка win-x64
============================

Рекомендуемая установка:
1. Запустите HUB-Desktop-Setup-<version>-win-x64.exe.
2. Подтвердите запрос контроля учётных записей Windows.
3. Откройте HUB Desktop из меню «Пуск» обычным пользователем.

Setup.exe сам проверит и при необходимости установит подписанные Microsoft зависимости:
- Microsoft Edge WebView2 Evergreen Runtime;
- Microsoft Windows App SDK Runtime 1.8 x64;
- Microsoft Visual C++ Redistributable x64.

MSI содержит только HUB Desktop и предназначен для управляемого развёртывания, где зависимости уже установлены. ZIP остаётся переносным вариантом и требует распаковки всей папки.

Важно:
- нельзя переносить только HUB.Desktop.exe: рядом нужны остальные файлы публикации;
- production URL закреплён на https://hubit.zsgp.ru/;
- вход выполняется существующей страницей HUB, desktop-клиент не хранит AD-пароль;
- автозапуск включается автоматически при первом запуске и может быть выключен в tray;
- один левый клик по значку tray открывает окно;
- если Windows toast недоступен, уведомление автоматически показывается через значок HUB в tray;
- пункт «Выйти» в tray полностью завершает приложение.

HUB Desktop Setup/MSI пока не подписаны корпоративным сертификатом. Файлы `.sha256` рядом с артефактами позволяют проверить целостность сборки.
