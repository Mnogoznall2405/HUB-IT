# Доступ к ИИ-агентам

## Правила

- Обычный ИИ-чат (`general-ai`, surface `general`) доступен активным пользователям.
- Все активные администраторы используют всех включённых агентов, в том числе при индивидуальном наборе прав.
- Остальные пользователи получают отдельное назначение для каждого агента. Право `chat.ai.sandbox` больше не предоставляет доступ.
- Назначения меняют администраторы и сотрудники с `settings.ai.manage`. Управляющий ботами может назначить доступ себе; само право управления не открывает агента.
- Карточки агента и сотрудника используют `app.ai_bot_access`. Изменения сохраняются сразу, отдельно от остальных полей карточки.
- При отзыве сохраняются история и доставленные файлы. Новые сообщения, задания, правки сообщений и подтверждения блокируются. Активные задания отменяются; OpenCode завершает очистку контейнера штатным worker. Повторная выдача доступа не возобновляет отменённые задания и разрешения на сессию.
- Уже начатую внешнюю операцию (например, отправку письма) отзыв не откатывает. Перед запуском действия доступ проверяется повторно. Завершённые задания на стадии доставки результатов сохраняют результаты.
- Назначение агента не расширяет права пользователя на почту, файлы, оборудование или другие бизнес-операции.

## API

- `GET /api/v1/ai-bots/{bot_id}/access?q=&offset=0&limit=50` — ограниченный список активных сотрудников для управляющего ботами; без секретов и полной карточки пользователя.
- `GET /api/v1/ai-bots/access/users/{user_id}` — назначения из карточки сотрудника.
- `PUT /api/v1/ai-bots/{bot_id}/access/{user_id}` с `{"allowed": true}` — назначение или отзыв.
- `GET /api/v1/chat/ai/conversations/{conversation_id}/access` — доступ владельца диалога к отправке. История имеет отдельную проверку принадлежности.

Сервер проверяет права независимо от интерфейса. Web/Desktop обновляют состояние композера при смене диалога, возврате в окно и каждые 15 секунд на видимой вкладке. Старые клиенты получают отказ сервера при запрещённой отправке.
