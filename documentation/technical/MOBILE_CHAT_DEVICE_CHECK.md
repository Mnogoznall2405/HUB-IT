# Мобильный чат — проверка на устройстве (12.10.2026)

Код-часть планов `MOBILE_CHAT_PLAN_2026-10-01.md` и `MOBILE_CHAT_TELEGRAM_PARITY_PLAN.md` закрыта; остаётся то, что видно только на устройстве. Журнал событий пишется автоматически и уходит одним файлом: **Настройки → Диагностика → «Поделиться отчётом»** (JSON, поле `chatDeviceLog`, формат отчёта 7). Журнал хранит имена событий и числа/короткие токены; текстов, названий чатов и идентификаторов в нём нет. Хранится до 400 последних событий, переживает перезапуск приложения; «Очистить диагностику» его обнуляет (сделайте это перед прогоном).

## Как проходить

1. «Очистить диагностику».
2. Пройти сценарии ниже, по одному разу.
3. «Поделиться отчётом» → прислать файл. Сценарии, где что-то пошло не так, отметьте текстом (номер из таблицы).

## Сценарии

| № | Что сделать | Ожидание | События в журнале |
|---|---|---|---|
| 1 | Открыть чат → «Новый чат», набрать поиск быстро | символы не теряются, курсор не прыгает, лист у нижнего края | `sheet_open/close {sheet:new_chat}`, `keyboard_show/hide` |
| 2 | Чат → ⋯ → «Управление папками», переименовать папку | поле над клавиатурой, кнопка «Назад» закрывает лист, не экран | `sheet_*{sheet:folders}` |
| 3 | Переслать сообщение, закрыть жестом и «Отмена» | лист закрывается, список не дёргается | `sheet_*{sheet:forward}` |
| 4 | Изменить группу (имя/участники) | лист поднимается над клавиатурой | `sheet_*{sheet:group_edit}` |
| 5 | Открыть/закрыть клавиатуру в треде и в списке чатов | нет скачков и мигания | `keyboard_show/hide {height, ms, mode}` |
| 6 | Выключить сеть, отправить 3 сообщения, включить сеть | уходят по порядку, без дублей | `outbox_retry`, `outbox_wake {reason:network\|foreground}`, `outbox_sent` |
| 7 | Отправить сообщение и свернуть приложение на 30+ с, вернуться | сообщение доставлено, обновления идут | `outbox_wake {reason:foreground}`, `ws_connect` |
| 8 | Удалить сообщение; убрать сообщение из очереди | диалог подтверждения поверх листа виден, действие выполняется | `msg_actions_open` |
| 9 | В AI-чате задать вопрос, свернуть приложение до ответа | приходит пуш в канал «HUB-IT Чат (ИИ)», ответ из пуша уходит | `send_result` (ответ из пуша в журнал не пишется — отметьте текстом) |
| 10 | Прокрутить длинный тред, «вниз», открыть фото и закрыть | без рывков | `thread_open {ms}`, `jump_bottom`, `media_open/close` |
| 11 | Упоминание вас в группе | в списке чатов значок «@» | — (визуально) |
| 12 | Холодный запуск приложения и открытие чата | время открытия видно в отчёте | `inbox_open {ms,count}`, `thread_open {ms}`, `uiTiming` |

Опорные замеры (для PERF-0) берутся из того же отчёта: `chatSendTiming` (tap→пузырь, tap→ack), `uiTiming`, `apiInflight`.

## Переключатель клавиатуры

`mobile-hub/src/chat/chatKeyboard.ts`: `CHAT_KEYBOARD_MODE = 'follow' | 'legacy'`. По умолчанию `follow`. Если на сценарии 5 есть скачки, для сравнения собрать сборку с `'legacy'`.

## Известные ограничения

- На Android `keyboard_*.ms` может быть 0 (платформа не отдаёт длительность).
- `ScreenSheet` не следует за пальцем при перетаскивании: закрытие по отпусканию (сценарии 1–4).
- Диалог подтверждения поверх листа на iOS не проверялся.
- Не реализовано: «пауза поллеров при pending в outbox» (S11 шаг 2.1), размеры вложений для фото без скачка рамки (нужны `width/height` в payload), функции из «Could» плана (отложенные/тихие сообщения, «Избранное», видео-кружки, GIF, правка истории, multi-choice опросы, выбор точки на карте).
