# Нативный чат: отправка, анимации и положение содержимого

Дата: 2026-09-05. Изменены исходники Expo Android; сборка APK и deployment не выполнялись.

## Поведение

- Удалена летящая копия текста из композера. Движется настоящий исходящий пузырь; его постоянная обёртка сохраняется после подтверждения сервером. Анимация появления — 250 мс, отдельная для каждого сообщения.
- Повторное нажатие на отправку того же значения до обновления поля блокируется. Следующее сообщение можно отправлять, пока предыдущий HTTP-запрос ещё выполняется. Ошибка удаления черновика больше не предотвращает начало отправки.
- Высота поля ввода меняется за 160 мс в пределах 44–120 dp. Панель ответа/правки раскрывается и сворачивается за 180 мс, измеряет содержимое и позволяет открыть оригинал. Ответ и правка фокусируют поле ввода.
- Свайп ответа/пересылки прерывает предыдущий возврат, возвращается без пружинного отскока и не срабатывает при преобладающем вертикальном движении. Порог и haptic сохранены; видимые альтернативы в меню остаются.
- Часы, галочки и ошибка занимают постоянный слот 24 × 16 dp. Переход статуса использует opacity, а резерв места в тексте не меняется между отправкой и прочтением.
- Фото имеют рамку, зависящую от ширины экрана, а не от момента загрузки и высоты области над клавиатурой. Превью показывается целиком через contain, поэтому у некоторых пропорций будут свободные поля. Полноэкранный просмотр сохранён. Слоты вложений сохраняются при замене локального сообщения серверным.
- Меню появляется с коротким fade/scale, измеряет свою область и переводит координаты пузыря из оконных в локальные. Всё содержимое меню прокручивается при недостатке высоты. Реакции в пузыре имеют прерываемый отклик на нажатие.
- При чтении истории включается сохранение видимого элемента. Уход вверх отменяет отложенное автопрокручивание. Изменение размера области списка удерживает низ только когда пользователь уже находится внизу.
- На iOS используется длительность системного события клавиатуры; Android сохраняет существующий adjustResize. Перед открытием emoji-панели клавиатура закрывается. Новые анимации учитывают reduced motion.

Это исправление слоя отображения и взаимодействия. Оно не реализует постоянную очередь исходящих после перезапуска, расширенные черновики с вложениями, цитирование фрагмента, серверную защиту массовой пересылки от дублей или отложенную отправку из функционального аудита.

## Проверки и сравнение

Пройдены 130 тестов в 16 наборах, включая существующие сценарии ответов, правки, голосовых, загрузки/отмены/повтора вложений, реакций и проверку отсутствия лишнего перерендера сообщений при вводе. Результат Jest: `artifacts/chat-motion-tests.json`. TypeScript проверяется через `tsc --noEmit`.

Исходный baseline установлен по коду до изменений; это не замеры FPS:

| Сценарий | До | После / доказательство |
|---|---|---|
| Визуальное представление отправляемого текста | Копия над вводом плюс настоящий пузырь | Дополнительная копия отсутствует; тест композера |
| Завершение анимации | Условная обёртка могла смениться непосредственно пузырём | Тест подтверждает один mount дочернего компонента без unmount при снятии анимации |
| Две отправки до HTTP-ответов | Требовалась проверка взаимодействия анимаций | Оба сообщения остаются по одному экземпляру, с разными client ID |
| Новый входящий при чтении истории | Сохранение позиции включалось только для загрузки истории | Тест проверяет включение сохранения позиции и отсутствие scrollToOffset |
| Статус доставки | Разная ширина спиннера и галочек, разный резерв текста | Тест подтверждает одинаковый размер слота для sending/sent/read/failed |
| Локальное фото → серверное | Размер мог меняться после onLoad | Тест подтверждает неизменную рамку при замене URI |
| Меню и клавиатура | Оконные координаты и начальные safe-area metrics | Тест на области 320 × 260 подтверждает ограничение размера и положения меню |

ADB вернул пустой список устройств. Реальные Android-анимации, большой системный шрифт, поведение разных клавиатур, FPS и память на устройстве не проверены. Наличие успешных Jest-тестов не заменяет эту приёмку. Для неё нужна отдельно разрешённая сборка обновлённого APK.

## Дополнение: вспышка предыдущего фото при перелистывании

В `ChatAuthenticatedImage.tsx` смена URI раньше оставляла старый `sourceUri` до выполнения passive effect. Теперь каждый URI получает отдельное состояние; поздние завершения загрузок и нативные события старого изображения игнорируются. Исправлена также ветка ошибки загрузки без локального URI: она показывает повтор загрузки вместо бесконечного индикатора.

В `ChatMediaViewer.tsx` завершение перелистывания раньше сбрасывало смещение старого кадра до обновления выбранного элемента. Теперь старый кадр остаётся за краем области просмотра, а новая страница получает отдельные значения анимации при неизменном внешнем Modal. Повторное нажатие во время перехода блокируется; завершения анимаций уже закрытой/сменившейся страницы игнорируются. Кнопки и свайпы используют один переход, reduced motion переключает страницу сразу. Загрузка оригинала не перекрывает превью индикатором.

Проверены 86 тестов в 7 наборах: `ChatAuthenticatedImage`, новый `ChatMediaViewer.test.tsx`, `NativeChatScreens`, `ChatVideoPlayer`, `ChatBubblePhoto`, `chatMedia`, `chatConversationGallery`. Артефакт: `artifacts/chat-viewer-regression.json`. `tsc --noEmit` завершился с кодом 0. Регрессии проверяют старый кадр, быстрые нажатия, позднее завершение перехода, запоздалую загрузку и повтор после сетевой ошибки.

Это подтверждение поведения компонентов в Jest, не покадровая проверка Android. Сборка APK, установка и deployment не выполнялись; окончательная визуальная приёмка на устройстве/эмуляторе остаётся обязательной.
