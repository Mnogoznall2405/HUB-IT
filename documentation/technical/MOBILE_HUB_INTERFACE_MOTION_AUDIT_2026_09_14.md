# Удобство мобильного интерфейса: жесты, движение, обратная связь

14 сентября 2026. Проверены текущие исходники, включая незакоммиченные изменения. Первоначальный аудит был диагностическим; после согласования «Начинай» выполнены исправления ниже. Чат исключён. Опубликованный APK не считается эквивалентом текущего дерева.

## Исправления после согласования

Все пять подтверждённых замечаний реализованы в исходниках:

- Просмотр фотографий почты: pinch 100–400%, ограниченное краями перемещение увеличенного изображения, видимые кнопки уменьшения/увеличения/сброса. Двухпальцевый жест не становится закрытием даже после отпускания одного пальца; увеличенное фото не перелистывается от pan. Масштаб сбрасывается при смене фото и ориентации. Однопальцевое направление фиксируется на жест; кнопки навигации сохранены.
- Отмена почтового действия: автоматический пятисекундный таймер удалён. Добавлена явная кнопка скрытия отмены. При новом действии, смене контекста или уходе со страницы прежняя отмена по-прежнему не переносится в другой ящик/выборку.
- Форма имени файла/папки: при сохранении явно отключены ввод, «Отмена», крестик и закрытие по фону/системному Back. Вместе со spinner показан текст «Сохраняем…».
- Нижнее меню: нажатие немедленно меняет фон/прозрачность, без задержки навигации.
- Общие фильтры: убраны скачки масштаба при нажатии; осталась обратная связь через прозрачность, одинаково пригодная при reduced motion.

Изменены `NativeMailImageViewer.tsx`, `NativeMailInboxScreen.tsx`, `NativeMyFilesSheets.tsx`, `NativeFilterControls.tsx`, `NativeFilterSheet.tsx`, `HubBottomNav.tsx`, тесты галереи/почты; добавлен `NativeMyFilesSheets.busy.test.tsx`. `NativeSheetHeader` получил необязательный `closeDisabled`, прежние вызывающие компоненты сохраняют поведение.

Узкие проверки: 4 набора / 44 теста и 2 набора / 133 теста — PASS. TypeScript и Android-export — PASS (`mobile-hub/artifacts/interface-motion-export-20260914`). Исторический диагностический `gesture.audit.case.jsx` ниже описывает прежнее ошибочное поведение; не запускать его как проверку исправления. Постоянные тесты теперь проверяют zoom, границы pan, отсутствие закрытия после pinch, сброс при смене фото и явное закрытие после сброса.

Итоговый прогон: **236 наборов / 1 434 теста PASS**, пути `src` без `/chat/`, внешний TCP заблокирован; лог `mobile-hub/artifacts/interface-motion-regression.log`. Дополненный тест защиты двухпальцевого движения при масштабе 100% также прошёл: `interface-motion-zoom-final.log`, 5/5. `git diff --check` — без ошибок. Общая приёмка исходников завершена; проверка физических жестов остаётся отдельной.

Реальная Android-приёмка остаётся открытой: `adb devices -l` пуст. APK не собирался/не публиковался, production не менялся. Новые жесты панелей и изменение flick-порогов из раздела UX-решений не добавлялись без аппаратного воспроизведения проблемы.

## Что уже сделано правильно

- Почтовый свайп отличает горизонтальное движение от вертикального, не запускает второе действие, пока первое не завершилось, сбрасывает позицию при прекращении жеста и учитывает disabled/reduced motion.
- У просмотра фотографий есть кнопки «Предыдущее», «Следующее», «Закрыть». Перелистывание сериализовано; завершение анимации старой страницы не меняет новую страницу.
- Переходы вложенных экранов учитывают reduced motion; основные вкладки переключаются без навязчивых анимаций. Отсутствие свайпа между рабочими вкладками само по себе не ошибка: его добавление может конфликтовать со списками и горизонтальными действиями.
- Нижнее меню скрывается при клавиатуре и одновременно исключается из касаний/дерева доступности. Скрытие сейчас мгновенное; необходимость плавного движения требует проверки вместе с реальной клавиатурой.
- «Исполняю»/«Созданные» рассчитываются по доступной ширине, не сжимаются в одну строку любой ценой. Тесты включают контейнеры 296/200 и fontScale 2 для общего переключателя.
- Выход из форм задач/публикаций ждёт сохранения черновика; ошибка сохранения оставляет форму открытой. Это полезнее декоративной анимации успешного выхода.
- Почтовые строки имеют accessibility actions для выбора и изменения состояния. Жесты не являются единственным технически доступным способом выполнить эти операции.

## Отдельные UX-решения, не подтверждённые баги

1. Панели фильтров выезжают снизу, действия файлов появляются через fade. Оба варианта допустимы, но можно согласовать один язык движения для одинаковых по смыслу панелей. Затемнение фона лучше отделить от движения содержимого.
2. Проверенные панели не реализуют drag-to-dismiss. Если добавлять, начать с заголовка панели, отделить его от вертикальной прокрутки и сохранить крестик/Android Back. Панели с несохранённым вводом должны проходить через существующую защиту выхода.
3. Свайпы галереи ориентированы на расстояние, не скорость. Короткий быстрый flick может не переключить фото. До изменения порогов проверить реальные движения большого пальца и случайные диагональные касания.
4. Фильтры задач применяются отдельной кнопкой, общий `NativeFilterSheet` применяет выбор сразу. У задач есть поясняющий подзаголовок; это не потеря данных. Желательно проверить, понимает ли пользователь разницу без инструкции.

## Проверки и ограничения

- Запущены **7 существующих наборов / 21 тест — PASS**: почтовые swipe/image viewer и модель жестов, нижнее меню, общие переключатели фильтров, reduced motion, защита выхода из формы. Лог: `mobile-hub/artifacts/interface-motion-audit-20260914.log`.
- **1 диагностический сценарий — PASS**: настоящий `NativeMailImageViewer` принимает двухпальцевое движение как закрытие. Использованы mocked PanResponder/нативное окружение и синтетическое событие; это не физическая проверка pinch. PASS здесь подтверждает текущее ошибочное поведение. Артефакт: `mobile-hub/artifacts/interface-motion-audit-20260914/gesture.audit.case.jsx`, лог рядом `gesture.log`. Файл не участвует в обычном Jest discovery. Первый холодный запуск превысил 5-секундный лимит теста; повтор с лимитом 15 секунд прошёл.
- `adb devices -l` — пустой список. Реальный установленный APK, TalkBack, системный edge-back, клавиатура, FPS/frame time, замедленный просмотр анимаций и фактическое обрезание на узком экране не проверены. Unit-тест с width/fontScale проверяет вычисления, не отрисовку текста на Android.
- Основной обзор охватывает общий shell/навигацию/модальные панели, почту и фото, формы файлов, фильтры задач и общие контролы. Это не заявление о ручном прохождении всех страниц приложения. В строительном разделе выполнен только поиск точек жестов/анимаций.
- Код приложения, зависимости и production не изменялись. Созданы этот отчёт, диагностический пример и логи. Deployment не требуется.
