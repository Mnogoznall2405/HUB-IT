# Мобильное приложение: компоновка и аудит — 13 сентября 2026

## Область и границы проверки

Проверены текущие исходники `mobile-hub`, включая незакоммиченные изменения. Версия source-кандидата — 1.1.37 / Android code 39; это не подтверждение опубликованного или установленного APK.

Аудит охватывает навигацию, общие контейнеры, фильтры, формы, просмотр файлов, состояния сети и сохранность пользовательского ввода. Выполнена навигация по всем группам экранов и их тестам. Это не построчная сертификация всего репозитория, не нагрузочный тест серверов и не ручная Android-приёмка каждого маршрута.

| P2: повтор создания после потери HTTP-ответа — требует серверного анализа | `taskApi.ts:createTask` не передаёт стабильный ключ попытки | Проверить серверный create-контракт и добавить согласованную идемпотентность; клиентского disabled недостаточно для потери ответа |
| P2: учёт места превью | Размер внутреннего кэша `expo-image` пока не входит в счётчик существующих файловых хранилищ | Явно разделить показатели либо дополнить достоверным учётом; не показывать приблизительный размер как общий |
| P2: актуальность документов | README содержит старый номер source-кандидата; migration map описывает часть уже реализованных модулей как отсутствующие | Синхронизировать карту с кодом и отдельно вести source/build/published/installed статусы, без неподтверждённых процентов готовности |

Новые модули до завершения сохранности данных и device acceptance не обязательны. Наибольшую пользу дадут восстановление незавершённой работы, предзагрузка превью и ясные статусы очередей. Офлайн-редактирование бизнес-данных требует отдельного решения по конфликтам и серверной идемпотентности.

## Проверки

- Браузерный стенд использует реальные `NativeFilterControls` и React Native Web; вместо иконок — заглушка. Размеры: 320/360/412/768 px; светлая/тёмная темы; 100/130/200% шрифта. Масштаб шрифта имитируется адаптером стенда, поскольку RN Web не воспроизводит системный Android fontScale автоматически.
- 24 сочетания: нет горизонтального переполнения, высота кнопок >=44 px. Скриншоты 320/light/100%, 412/dark/100%, 320/light/200% просмотрены. Сценарии включают два scope задач, четыре типа статистики, пять источников уведомлений, статусы и длинный chip.
- Артефакты: `mobile-hub/artifacts/layout-audit-20260913/final-metrics.json` и PNG в той же папке. Это изолированный стенд компонентов, а не снимки авторизованных Android-экранов.
- TypeScript: `npx tsc --noEmit` — успешно.
- Полный Jest с блокировкой внешней сети: 284 набора, 1809 тестов — успешно. Лог: `mobile-hub/artifacts/layout-audit-20260913/jest-final.log`. Первоначальный прогон обнаружил зависимость отдельных компонентов от обязательного SafeAreaProvider; после перехода на существующий fallback-паттерн полный прогон повторён успешно.
- Финальный Android-export — успешно, 2142 модуля; результат: `mobile-hub/artifacts/layout-export-20260913`, лог: `mobile-hub/artifacts/layout-audit-20260913/export-final.log`. Это JS/assets export, не сборка APK.
- `git diff --check` для изменённых исходников — без ошибок пробелов; Git сообщает только о принятом преобразовании LF/CRLF. `adb devices` — список устройств пуст.
- APK не собирался и не публиковался; устройства для ADB нет. Поворот, жесты фото, Android-клавиатура, TalkBack и реальные API-записи остаются непроверенными.
