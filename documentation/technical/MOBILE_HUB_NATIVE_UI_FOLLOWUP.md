## Проверки

Пройдены TypeScript (`tsc --noEmit`) и 153 теста в 16 наборах. Машинный результат: `artifacts/native-ui-regression.json`.

Добавлены или обновлены:

- `screens/computers/NativeComputersScreens.test.tsx`: после загрузки 100 записей таймер обновляет все 100, включая изменённую запись второй страницы.
- `screens/myFiles/NativeMyFilesScreen.test.tsx`: повторный опрос без чтения кэша, пропуск перекрывающихся опросов, уход с экрана, игнорирование старого ответа после ручного обновления.
- `screens/mail/NativeMailScreens.test.tsx`: письмо можно открыть при отказе счётчиков папок.
- `screens/addressBook/NativeAddressBookScreen.test.tsx`: почта и чат через карточку, включая ранее сохранённую офлайн-связь с чатом.
- `screens/account/NativeAppSettingsScreen.test.tsx`: частичный результат, повтор только неготовых разделов, расхождение успешной записи и итоговой проверки.
- `screens/tasks/NativeTaskScreens.test.tsx`: при 1000 синтетических комментариев монтируется ограниченная часть списка, последний комментарий сразу не монтируется.
- `navigation/useNativeBottomNavInset.test.tsx`: изменение текущего нижнего inset с 0 до 34 и скрытая навигация.

Также пройдены существующие проверки производительности списков компьютеров, файлов, почты, адресной книги и задач; тесты API файлов, автономной подготовки, экранов аккаунта и нижней навигации.

## Сравнение и ограничения

Исходный baseline установлен аудитом кода перед правками, без Android-профилирования:

| Сценарий | До | После, подтверждено локальными тестами |
|---|---|---|
| 100 загруженных компьютеров, автообновление | Запрашивались первые 50 с заменой всего списка | Все 100 сохранены и обновлены |
| Тихий опрос файлов | Одно чтение защищённого кэша на каждый опрос | Ноль дополнительных чтений кэша при опросе |
| Опрос файлов вне фокуса | Не было проверки фокуса | Новые запросы не запускаются; поздний ответ не применяется |
| Большое обсуждение | `.map` создавал все элементы комментариев | Тест на 1000 комментариев подтверждает менее 100 смонтированных элементов |

Обновление компьютеров теперь передаёт больше данных пропорционально открытому диапазону. Почта по-прежнему ожидает завершения вспомогательных запросов, но их отказ больше не блокирует успешные данные. Виртуализация комментариев уменьшает число элементов интерфейса, а не объём сетевого ответа.

`adb devices -l` вернул пустой список. Поэтому новые экраны не проверены визуально на Android, не измерялись FPS, память и задержки на устройстве. Существующий APK этих изменений не содержит. Для проверки установленного приложения нужна отдельно разрешённая сборка и запуск на эмуляторе/устройстве.
