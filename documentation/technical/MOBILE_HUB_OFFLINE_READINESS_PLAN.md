# План готовности mobile-hub к автономной работе

Дата актуализации: 2026-08-26.

## Цель и границы

Автономный режим остаётся безопасным read-only режимом: ранее сохранённые данные можно читать без сети, изменения блокируются, а только явно поддержанные идемпотентные действия остаются в очередях. Полная локальная копия backend и офлайн-редактирование всех сущностей в этот этап не входят. Нативный интерфейс Chat этим проходом не изменяется.

## Выполненный план

| Этап | Статус | Результат |
|---|---|---|
| Восстановление доступа к offline-кэшу портала | готово | Для уже открытой online-сессии можно биометрически разблокировать только локальный ключ кэша без повторной серверной авторизации |
| Безопасное хранение крупных снимков | готово | Снимки вынесены из SecureStore в app-private файловый кэш, зашифрованный AES-256-GCM; в SecureStore остаётся только пользовательский ключ |
| Защита от смешивания пользователей | готово | Имена файлов почты и задач содержат ID текущего пользователя; logout очищает эти кэши и их размер входит в диагностику |
| Read-only при потере сети | готово | Любая мутация общего native API блокируется до транспорта с кодом `HUBIT_OFFLINE_READ_ONLY`; GET/HEAD/OPTIONS разрешены |
| Восстановление очередей | готово | Очередь команд и быстрых ответов запускается сразу при переходе offline → online, а также при старте и возврате приложения |
| Единая подготовка | готово | В нативных настройках кнопка заранее сохраняет Главную, стандартный список задач и Входящие без WebView и показывает частичный результат |
| Точные карточки | готово с ограничением | Открытые online письма, переписки и задачи сохраняются отдельно; произвольные ещё не открытые карточки offline не обещаются |
| Автоматические проверки | готово | TypeScript, 204 Jest-набора / 1013 тестов, Expo Doctor 21/21 и Android export прошли |

## Обязательная ручная приёмка

- Подключить физический Android и выполнить cold start без сети после online-входа и включения биометрии.
- Проверить чтение Главной, списка задач, Входящих и заранее открытых карточек писем/задач.
- Убедиться, что создание, изменение, удаление и отправка не дают ложного успеха без сети.
- Выполнить не менее 20 циклов offline → online и проверить однократную отправку очередей без дублей.
- Проверить logout, смену пользователя и отсутствие данных предыдущей учётной записи.
- Проверить поведение после системной очистки cache storage: приложение должно показать честный cache miss, а не пустые или чужие данные.

## Критерий завершения

Задача считается принятой после зелёной автоматической проверки и ручной матрицы на физическом Android. Android export подтверждает собираемость JavaScript-бандла, но не заменяет установку APK, биометрию, системное управление cache и реальные переходы сети.
