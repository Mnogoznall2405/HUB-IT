## 2. Остаточные дефекты

### MB3-03. Правки после создания задачи не применяются

`mobile-hub/src/screens/tasks/NativeTaskCreateScreen.tsx:369-381`, `:409-431`, `:437-451`, `:495-496`.

Восстановление теперь строит `pending` из текущих `files` (это исправлено), но:

- recovery-ветка не вызывает `updateTask`, поэтому изменения названия, описания, срока, исполнителей и чек-листа после создания задачи теряются;
- форма остаётся редактируемой, кнопка называется «Повторить загрузку»;
- при частичном создании (`created.failed`) строка `:421` записывает `uploadRecovery: null`, хотя `notUploaded` может быть больше нуля. Вложения успешно созданных задач после этого восстановить нельзя.

**Что осталось сделать:** в recovery-ветке применять изменения метаданных к `recovery.taskIds`; не обнулять recovery, пока есть недоставленные файлы; дать исключение конкретного файла из recovery.

### MB3-11. Deep link на пост/комментарий открывает список

`mobile-hub/src/navigation/moduleRegistry.ts:272-276`; `mobile-hub/app/(shell)/feed/index.tsx:1-5`; `mobile-hub/src/screens/feed/NativeFeedPostScreen.tsx:98-102`.

`nativeFeedDestinationFromPortalPath` корректно возвращает `/(shell)/feed/[postId]` с `commentId`, но `routePathFromHref` превращает его в `/feed?post=<id>` (комментарий — в hash). Expo Router ведёт `/feed` на `feed/index`, который не читает `post`. Экран поста уже умеет и `postId`, и `commentId`, но маршрут до него не доходит.

**Что осталось сделать:** возвращать `/feed/<postId>?commentId=<id>` либо перенаправлять `post` из `feed/index` на экран поста; hash `#feed-comment-...` в параметр не превращается.

### MB3-16. Дедлайт непрочитанного не проверяет ящик

`mobile-hub/src/mail/useMailList.ts:311-326`, `:357-365`.

`applyUnreadDelta` теперь принимает `targetFolder` и вызывается с папкой письма, но `applyUnreadDeltaLocal` обновляет `summary` и `folderTree` без проверки, что `scopedMailboxId` совпадает с текущим видимым ящиком. При открытом списке ящика A событие о письме делегированного ящика B уменьшит счётчик A. Дефект низкой severity, но остаётся.
