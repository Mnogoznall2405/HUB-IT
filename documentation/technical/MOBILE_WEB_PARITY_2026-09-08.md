# Android: дополнения меню и строительный модуль

Дата: 2026-09-08. Локальный кандидат: 1.1.30 / versionCode 32. Публикация не входит в этот этап.

## Что добавлено

- Настройки → Администрирование: вход к пользователям и правам из привычного раздела настроек.
- В назначаемые права добавлены `construction.read` и `construction.write` — это два отсутствовавших значения относительно веб-констант.
- Пользователи AD: поиск, отдельный импорт или синхронизация выбранной учётной записи с подтверждением. Конфликт локальной учётной записи не разрешается автоматически.
- AI-боты: список, создание, редактирование основных параметров модели/инструкции/файлов/состояния, история запусков. Изменение основных полей не перезаписывает настройки инструментов и область доступа.
- Система: контролёр актов, IP allowlist административного входа, редактор существующих серверных переменных. Переменные запрашиваются только после отпечатка и включения защиты экрана; значения не кешируются, скрываются при сворачивании/уходе с экрана. Сохранение требует подтверждения внутри интерфейса. Перезапуск/деплой автоматически не выполняются.
- Объекты строительства: отдельный пункт меню и нижней навигации; список, поиск, фильтр вида объекта, карточка и команда, направления, активные/исторические заявки, состав заявки, следующая страница и переходы из ссылок веба.
- Строительные данные, просмотренные пользователем, сохраняются через существующее зашифрованное хранилище снимков. Офлайн доступны уже открытые выборки; административные разделы без сети не работают.

## Ограничение AD, подтверждённое кодом

Веб-меню допускает `ad_users.read` / `ad_users.manage`, но `/ad-users/import-candidates`, `/import-to-app`, `/sync-to-app` используют `get_current_admin_user`. Поэтому нативный раздел импорта ограничен ролью admin; серверная политика не ослаблялась.

## Что ещё требуется для полного функционального совпадения с вебом

Это оставшиеся функции, а не скрытые под новыми пунктами готовые возможности:

1. **Строительство:** создание/редактирование управляемых объектов и команды, история ролей, работы и графики, расширенные фильтры заявок и подробная история движения документов. Новый мобильный модуль реализует просмотр. Запросы `construction.write` из него пока не выполняются.
2. **Офлайн строительства:** общая предварительная загрузка через «Подготовить к работе без сети». Сейчас сохраняются просмотренные страницы и карточки.
3. **AI-боты:** редактор наборов инструментов, параметров много-базового доступа, областей базы знаний, подробные трассы запусков. Существующие настройки сохраняются при редактировании основных полей.
4. **AD:** массовая синхронизация, назначение филиалов, подробный отчёт статуса синхронизации и другие операции веб-страницы. В APK доступны операции над выбранным пользователем.
5. **Система:** управление группами хранилища паролей и подробная история/план применения серверных переменных. Потребность перезапуска отмечается, автоматического применения к службам нет.
6. **Другие пункты веб-меню без нативного раздела:** билеты (`/tickets`), заявки МПЗ (`/it/requests`), сети, ВКС, DLP, статистика и база знаний. Их наличие проверено по `frontend/src/components/layout/navigationConfig.jsx` и сопоставлено с `mobileNavItems.ts`.
