# PostgreSQL HUB-IT на TMN-SRV-DB-06

Перенос выполнен 8 сентября 2026 года. Рабочая БД `hubit_chat` находится на
`TMN-SRV-DB-06` (`10.103.0.10:5432`); приложение продолжает работать на
`TMN-SRV-APP-02` (`10.103.0.217`). SQL Server и файловые вложения не переносились.

## Размещение и подключения

- Ubuntu 24.04.4 LTS, PostgreSQL 16.15, кластер `16/main`.
- Данные: `/var/lib/postgresql/16/main`.
- Конфигурация HUB-IT: `/etc/postgresql/16/main/conf.d/hubit.conf`.
- Правила подключения: `/etc/postgresql/16/main/pg_hba.conf`.
- PostgreSQL включён в автозапуск; `max_connections=300`, `shared_buffers=1GB`.
- Прикладная роль `hubit_chat_app` не имеет superuser, CREATEDB или CREATEROLE.
- Сетевой доступ разрешён только этой роли к `hubit_chat` с `10.103.0.217/32`,
  через `hostssl` и SCRAM. Администрирование на DB-06 — локально через OS identity.
- В корневом `.env` изменены только `APP_DATABASE_URL`, `CHAT_DATABASE_URL`,
  `SCAN_DATABASE_URL`: все указывают на DB-06 с `sslmode=require`.
  Пароли и полные строки подключения в документации не приводятся.

Источник использовал PostgreSQL 16.13 на Windows, UTF-8 и locale
`Russian_Russia.1251`. На Linux выбрана `ru_RU.UTF-8`; timezone
`Asia/Yekaterinburg`, DateStyle `ISO, DMY` и русский text search сохранены.
Индексы построены заново. Полная эквивалентность порядка сортировки разных ОС
не проверялась. Параметры locale зависят от платформы:
[документация PostgreSQL](https://www.postgresql.org/docs/16/locale.html).

## Резервные копии и откат

На APP-02: `C:\Project\Image_scan\deploy_backups\postgres-db06-20260908`.
Доступ к каталогу ограничен текущим администратором и SYSTEM. Содержимое:
`.env.before`, пробный и финальный дампы с SHA-256 manifests,
`source-final.json`, `target-final.json`, `comparison.json`, `postcheck.json`,
`ROLLBACK.md`, копии документов перед запуском.

На DB-06 дампы находятся в `/var/lib/postgresql/hubit-migration` (каталог 0700,
файлы 0600, владелец postgres); исходная конфигурация нового кластера и журналы
восстановления — в `/var/backups/hubit-db06-20260908`.

Старая `hubit_chat` на APP-02 не удалена. После возобновления работы на DB-06
**нельзя просто вернуть старый `.env`**: это потеряет доступ к новым записям.
Для отката сначала остановить всех писателей, сохранить свежий дамп DB-06,
выполнить проверенный обратный перенос / согласовать новые записи и только
затем менять подключения. Подробности локальной подготовки — в `ROLLBACK.md`.

Эти архивы — снимки переноса, а не настройка регулярного резервного копирования.
