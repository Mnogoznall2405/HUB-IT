# Полная карта интерфейса HUB-IT

Один файл: все страницы веб-портала, переходы между ними, элементы, действия, состояния, права и тестовые данные.

- **Дата среза:** 14.11.2026
- **Стенд живой проверки:** `https://hubit.zsgp.ru` (production); чтение + одна обратимая тестовая запись (папка в «Моём диске», убрана в корзину)
- **Проверяющий пользователь:** `kozlovskii_me` — роль `viewer`, кастомные права (73), отдел технической поддержки
- **Источники:** `WEB-itinvent/frontend/src/App.jsx`, `components/layout/navigationConfig.jsx`, `pages/*`, `e2e/*.spec.js` + живой прогон в Chrome через browse-плагин
- **Связанные документы:** [REPOSITORY_MAP.md](REPOSITORY_MAP.md), [USER_GUIDE.md](USER_GUIDE.md) (бот), [TESTING.md](TESTING.md)

> Документ описывает **веб-портал** (React SPA). Desktop-оболочка (`desktop/`) показывает те же экраны в WebView2; мобильное приложение (`mobile-hub/`) имеет собственный UI и здесь не описано.

## 5. Страницы (детально)

Ниже — фактический состав экранов, снятый в живом приложении 14.11.2026 (подписи кнопок/вкладок приведены как в UI).

### 5.1 Главная — `/dashboard`

- **Файл:** `pages/Dashboard.jsx`
- **Назначение:** стартовый экран: приветствие, сводка дня, быстрые действия, новости.
- **Экран:**
  - Приветствие «Доброе утро/день, <Имя>» + текущая дата.
  - Блок «Что умеет HUB» с кнопкой «Посмотреть» и крестиком «Скрыть подсказку».
  - Сводка «Всё спокойно» / просроченные задачи и обязательные подтверждения.
  - Быстрые действия: «Создать задачу», «Открыть чат», «Написать письмо», «Все задачи», «Предложить улучшение HUB».
  - Виджеты: «Задания 1С» (персональные согласования и поручения), список задач, «Почта» (непрочитанные), «Чат», «Уведомления», новости компании.
  - Кнопки обновления/настройки: «Обновить главную», «Настроить главную».
- **Переходы:** `/tasks?create=1`, `/chat`, `/mail?compose=new`, `/feed`, карточки задач и новостей.
- **Состояния:** пусто («Всё спокойно»), загрузка виджетов по отдельности.

### 5.2 Лента — `/feed`

- **Файл:** `pages/Feed.jsx`
- **Назначение:** корпоративная лента публикаций.
- **Экран:** композер «Что происходит в компании? Создать публикацию»; фильтры «Все», «Новое · N», «Важное», «Мои подразделения», «Сохранённые»; «Открыть фильтры»; вкладки «Черновики», «Запланированные», «Архив».
- **Действия с постом:** реакция «Нравится», «Любовь», «Выбрать другую реакцию», просмотр всех отреагировавших, «Открыть комментарии», «Поделиться публикацией», «Сохранить публикацию», «Показать ещё».
- **Форма:** композер «Что происходит в компании?» → «Создать публикацию» (текст, вложения, категория/тег). Диалог «Открыть фильтры»: «Поиск в ленте», «Категория», «Тег», «Закрыть фильтры».
- **Переходы:** карточка публикации, комментарии, профиль автора.
- **Состояния:** пустая лента, «Показать ещё» для пагинации.

### 5.3 Задачи — `/tasks`

- **Файл:** `pages/Tasks.jsx`
- **Назначение:** рабочие задачи сотрудника и отдела.
- **Экран:** вкладки **Список / Сроки / Календарь / Гант / Доска / Аналитика**.
  - Счётчики: «Открыто», «Проверка», «Просрочено», «Архив».
  - Роли: «Исполняю (N)», «Созданные», «Отдел», «На контроле».
  - Подфильтры: «Все», «К проверке», «Просроченные», «С новым в архиве».
  - «Развернуть фильтры», сортировка («Дата изменения, сначала новые»).
- **Действия:** «Новая задача» (модальная форма), «Обновить», «Справочники», открытие карточки, смена статуса, комментарии, чек-лист, вложения, «к проверке».
- **Форма «Новая задача»:** поля «Что нужно сделать» (минимум 3 символа), «Описание», «Исполнители», «Крайний срок» / «Без срока», «В приоритете», «Файлы», «Чек-листы», «Проект: Общие задачи», «Контролёр», «Наблюдатели», «Полная форма», «Дата постановки», «Приоритет»; кнопки «Отмена», «Создать задачу».
- **Переходы:** `/tasks?create=1` с главной; карточка задачи; переходы на связанные объекты.
- **Состояния:** пустой список по фильтру, ошибка загрузки/повтор.

### 5.4 Билеты — `/tickets`

- **Файл:** `pages/Tickets.jsx`
- **Назначение:** учёт заявок/билетов сотрудников (в т. ч. персональные данные).
- **Экран:** переключатели «Сотрудники» / «Справочник объектов»; поиск; фильтры «Объекты», «Статусы»; таблица (№, дата подачи, ФИО, подразделение, должность, серия/номер, дата выдачи, статус); пагинация.
- **Действия:** «Создать заявку», «Обновить», «Экспорт», открытие строки/карточки, редактирование.
- **Форма «Создать заявку»:** «Сотрудник» * (ищите в ЗУП — подтягивается автоматически), «Объект» * (название или код), «Город / населённый пункт вылета»; кнопки «Отмена», «Создать».
- **Права:** просмотр персональных данных — `tickets.personal_data.read`; запись — `tickets.write`.

### 5.5 Чат — `/chat` (+ `/chat/open`)

- **Файл:** `pages/Chat.jsx`, `pages/ChatOpen.jsx`
- **Назначение:** корпоративный мессенджер + ИИ-ассистент + личные заметки.

## 6. Сквозные сценарии

### 6.1 Вход
1. `/login` → форма пароля (`password-auth-form`, поля `username`, `password`) или вход по passkey (если включён `login-mode`).
2. Возможна 2FA (`/auth/verify-2fa-login`), доверенные устройства (`/auth/trusted-devices`).
3. После входа — редирект на сохранённый путь или первый доступный раздел.
4. Первый вход: `/about` (онбординг), затем рабочий раздел.

### 6.2 Главная → задачи
1. `/dashboard` → «Создать задачу» (или `/tasks?create=1`).
2. Форма задачи → сохранение → задача появляется в списке «Исполняю/Созданные».
3. Карточка задачи → комментарии, чек-лист, смена статуса, вложения.

### 6.3 Чат
1. `/chat` → список диалогов (Личные / Беседы / Задачи) или вкладка «ИИ».
2. Открытие диалога → история, ввод сообщения, вложения, реакции, звонок.
3. Уведомление о новом сообщении → переход в диалог (в т. ч. `/chat/open#…` из Desktop).
4. Раздел «Заметки» — личные заметки внутри чата.

### 6.4 Почта
1. `/mail` → подключение ящика (если не подключён) → папки и письма.
2. `/mail/compose` — новое письмо; `/mail?compose=new` с главной.

### 6.5 Инвентарь
1. `/database` → вкладка «Оборудование» → карточка единицы → история, фото, QR.
2. «Определить ПК» / QR-сканер — быстрый поиск.
3. Переключение базы (`ITINVENT`/локальная) сохраняется в `selected_database`.

### 6.6 Файлы
1. `/my-files` → «Создать» (папка/документ/загрузка) → редактор `/my-files/edit/:fileId`.
2. Публикация ссылки → `/shared-files/:token` (без авторизации), папки → `/shared-folders/:token`.

### 6.7 Scan Center
1. `/scan-center` → выбор филиала → «Запустить скан» / «Обновить».
2. Очередь, OCR-статистика, ITINVENT-счётчики, разбор документов.
