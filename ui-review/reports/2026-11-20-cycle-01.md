## Что не включено в первую очередь

| Кандидат | Решение |
| --- | --- |
| Скопировать ширину списка, цвета и размеры шрифта Telegram | Отклонено: у официальных кадров неизвестны DPI и версия; ширину определяет пригодность ленты в HUB, а палитра остаётся собственной. |
| Убрать корпоративную панель целиком ради сходства | Отклонено: работа с другими функциями HUB должна оставаться доступной; адаптация — часть UI-002. |
| Оптимизировать скролл только потому, что в XAML есть сложные шаблоны и тени | Отклонено без замеров. Демостенд построил 1000 элементов в модели, но это не тест задержек и не нагрузка серверной пагинации. |
| Светлые строки таблиц в тёмной теме у «Групп доступа» и «Склада 1С» | Отложено за пределами первой очереди чата: видно на [матрице доступа](../screenshots/before/wpf-render/17-groupsaccess.png) и [складе](../screenshots/before/wpf-render/27-warehouse.png). Сначала проверить общий стиль таблиц и состояние выбора, не заводить две задачи на разметку до проверки общего источника. |

- `dotnet test desktop/Hub.Desktop.Tests/Hub.Desktop.Tests.csproj -c Release --artifacts-path <temp> --filter "FullyQualifiedName~NativeScreenshots|FullyQualifiedName~NativeChatViewModelTests|FullyQualifiedName~NativeChatDraftTests|FullyQualifiedName~NativeChatGroupingTests"`: **193 прошли, 0 упали, 0 пропущено** на проверенном снимке сборки. Снимки не являются автоматическим тестом визуального соответствия. Утверждение исполнителя о более широком прогоне не зачислено как проверка куратора.
- Окно Win32/WPF запущено на отдельном STA-стенде с вымышленными аккаунтами, `App.xaml` и `FakeHubApiClient`. Сняты оригинальные пиксели окна при 1024×600 и 1280×720 / 100%. Карточку открывали в том же чате; ошибку истории имитировали только для истории, кнопку нажали через WPF UI Automation. Маршрутизированный Escape закрыл подтверждение удаления, но не настройки группы. Поиск открылся через UI Automation кнопки в шапке и закрылся по routed Escape. Нет оснований делать вывод о производительности или готовности релиза.
